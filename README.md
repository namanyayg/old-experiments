# Old experiments

Personal web experiments by Namanyay Goel, recovered from Cloudnommy on October 22, 2026.

- **MusiCose**: the original horizontal music-site demo, with keyboard navigation, deep links and mobile scrolling repaired. Its fictional contact form is disabled.
- **MinSlide**: the original four-slide demo, with accessible controls. The externally hosted images were not on the server; solid colors explicitly stand in for them.

Only reviewed static HTML, CSS and JavaScript are published. Source came from the surviving `index.htm.bak.bak` files; the server's PHP redirect wrappers are excluded. The complete private source archive is retained separately. `provenance.json` records original-file SHA-256 hashes. No server runtime, credentials, client files, tracking or active forms are included.
